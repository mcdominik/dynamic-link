# HTTP Redirection Core

Core built with [NestJS](https://nestjs.com/) for managing and handling dynamic link redirection. 

## 📝 Description

This project serves as the foundation for a dynamic link redirection service. It is designed to handle incoming requests, resolve dynamic aliases to their respective target URLs, and redirect users seamlessly. Built with TypeScript and NestJS, it offers a robust, modular, and easily extensible architecture.

## 💡 Use Cases:
- dynamic QR codes
- url shortener
- general purpose link redirection
  
## 🚀 Tech Stack

* **Framework:** [NestJS](https://nestjs.com/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Testing:** Jest

## 📦 Installation

Clone the repository and install the dependencies:

```bash
# Clone the repository
$ git clone [https://github.com/mcdominik/dynamic-link.git](https://github.com/mcdominik/dynamic-link.git)

# Navigate into the directory
$ cd dynamic-link

# Install dependencies
$ npm install
